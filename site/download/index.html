Baixar o WhatsApp MCP Local

Grátis, para macOS, Windows e Linux. Sempre a versão mais recente. O que mudou

O WhatsApp MCP Local roda no computador. Abra esta página nele para baixar.

Seu sistema

macOS

macOS 11 ou mais novo, em Macs com Apple Silicon ou Intel.

Baixar para macOS

WhatsApp-MCP.dmg

  1. Abra o arquivo baixado.
  2. Arraste o WhatsApp MCP para a pasta Aplicativos.
  3. Abra o app pela pasta Aplicativos.
Seu sistema

Windows

Windows 10 ou 11, 64 bits. Não pede senha de administrador.

Baixar para Windows

WhatsApp-MCP-Setup.exe

  1. Rode o instalador baixado.
  2. Se aparecer “O Windows protegeu o computador”, clique em Mais informações e depois em Executar assim mesmo. O instalador ainda não é assinado.
  3. No fim, deixe marcado Abrir o WhatsApp MCP.
Seu sistema

Linux

Distribuições recentes, em x86_64 ou ARM64.

Baixar para Linux

WhatsApp-MCP-x86_64.AppImage

  • AppImage para ARM64
  • Pacote .deb para Ubuntu e Debian (x86_64)
  • Pacote .deb para Ubuntu e Debian (ARM64)
  1. AppImage: torne o arquivo executável com chmod +x WhatsApp-MCP-*.AppImage e abra.
  2. Pacote .deb: instale com sudo apt install ./whatsapp-mcp_*.deb.

Depois de instalar

  1. Leia o QR code com o celular

    No WhatsApp, entre em Configurações › Dispositivos conectados › Conectar um dispositivo e aponte a câmera para o código do app. Se preferir, peça um código para digitar no celular.

  2. Conecte o Claude

    Um clique liga o Claude Desktop (chat e Cowork) ou o Claude Code. Para outras ferramentas que aceitam MCP, o app dá um texto pronto para colar.

Prefere o terminal?

Para um computador sem tela, que fica ligado o tempo todo, existe a versão de linha de comando, sem janela. Funciona no macOS e no Linux, sem sudo, e abre o mesmo painel no navegador.

curl -fsSL https://raw.githubusercontent.com/BrOrlandi/whatsapp-mcp-local/main/install.sh | bash

Também dá para pedir ao Claude Code, ao Cowork ou a outro agente que instale seguindo o guia do repositório.
