Experimente:

Três passos, sem terminal

  1. Baixe e abra o app

    Tem versão para macOS, Windows e Linux. No Mac, arraste para Aplicativos; no Windows, rode o instalador.

  2. Leia o QR code com o celular

    No WhatsApp, entre em Dispositivos conectados e aponte a câmera para o código. Se preferir, peça um código para digitar no celular.

  3. Conecte o Claude

    Um clique liga o Claude Desktop (chat e Cowork) ou o Claude Code. Para outras ferramentas, o app dá um texto pronto para colar.

Tudo acontece no seu computador

Não há servidor nosso no meio. O app entra no WhatsApp como um dispositivo conectado, igual ao WhatsApp Web, guarda as mensagens na sua máquina e só atende programas dela.

As mensagens ficam com você

O que chega do WhatsApp fica guardado no seu computador. Não tem conta para criar nem mensalidade.

Áudios viram texto aqui mesmo

Quando você pede, o Whisper transcreve no próprio computador, sem o áudio sair da máquina. Com a GPU do Mac ou uma placa NVIDIA, leva segundos.

Fica na barra de menus

Fechar a janela não encerra o app. Ele abre sozinho quando o computador liga, e o ícone mostra se o WhatsApp está conectado.

Atualiza sozinho

Duas vezes por dia o app procura uma versão nova. Um clique baixa, confere o arquivo e reinicia já atualizado.

Antes de instalar

Use por sua conta e risco

O WhatsApp não tem API oficial para contas pessoais. O app usa o wacli, um cliente não oficial, e a conta pode ser desconectada ou restringida.

O computador precisa estar ligado

Para receber mensagens, o app precisa estar aberto. Se o computador ficar desligado por pouco tempo, o WhatsApp entrega o que ficou pendente quando ele volta.

Claude neste computador

Funciona com o Claude Desktop, o Claude Code e outras ferramentas que aceitam MCP nesta máquina. O claude.ai no navegador e o app do celular não alcançam o seu computador; para eles, a alternativa é a versão servidor, no lugar do app.
