What your AI can do in WhatsApp

The 40 tools WhatsApp MCP gives your AI tool, in plain words. It picks which one to use from what you ask.

Read and search Keep track Send and reply Voice messages, photos and files Manage groups Check the connection

Read and search

The AI reads what has already reached this computer. The longer the app runs, the more history it has to look through.

List chats

The most recent chats first, with pinned ones on top, as on the phone.

list_chats In the recipes: Watch for keywords

Read a chat

The messages of one chat over a period, for the AI to summarize. Voice messages already transcribed come with their text. For a long period it can count the messages before reading them.

get_chat_messages In the recipes: Watch for keywords, A group's daily summary, Read the document or photo that came in, A record of what was agreed

Search messages

Searches for words across every stored message and the voice messages already transcribed, in one chat or all of them, over a period or any date. It also says how far back the stored messages go, so an empty result isn't mistaken for a chat that never happened.

search_messages In the recipes: Watch for keywords, A record of what was agreed

See a message in context

The messages just before and after one, for example a search result, to understand what it was answering.

get_message_context

See what's unread

The chats with unread messages, as the phone shows them, with the latest messages of each. Reading on the phone clears them here too.

list_unread

See who's waiting for a reply

The chats where the latest message came from the other person, with how many messages wait and since when. Direct chats by default; groups when asked, or only those where someone mentioned you. An "ok", a "thanks" or a 👍 doesn't count as waiting.

list_unanswered In the recipes: Summary of what's still unanswered

See where you were mentioned

The messages where someone mentioned you in a group (the @ with your name), newest first, each saying whether you wrote in that chat afterwards.

list_mentions

List contacts

The address book of the connected account, as it reached this computer, filtered by name or number.

list_contacts

List groups

The groups the account belongs to.

list_groups In the recipes: A group's daily summary

See a group

A group with its members, with a search for one person in a large group. It can also fetch the group fresh from WhatsApp.

get_group

Count messages

Counts messages by chat, by person, by day or by month, without reading them: who talks most, how busy a group was each month, how big a job is before starting it.

message_stats

Export messages to a file

Writes messages to a file on this computer, oldest first, to analyse a whole archive with a script or a tool that reads files, without loading it all into the conversation. Transcribed voice messages go with their text.

export_messages

Bring older messages

Asks the phone for messages older than the stored ones, one chat at a time, going back in time. The phone needs to be online, and WhatsApp itself limits how far back it goes.

sync_history

Keep track

Marks that stay with you: the other person sees nothing.

Mark as handled

Records that a chat was dealt with, so it leaves the waiting-for-a-reply and unread lists until someone writes in it again. Kept on this computer only: nothing is sent.

mark_handled In the recipes: Summary of what's still unanswered

Snooze a chat

Keeps a chat off those lists until a set time, or until someone writes in it first. Kept on this computer only.

snooze_chat In the recipes: Summary of what's still unanswered

Archive, pin or mute

Archives, pins or mutes a chat, or undoes it. It only changes how your own WhatsApp shows the chat: nothing is sent and the other side sees nothing.

organise_chat

Mark as read

Marks a chat as read on all your devices, as opening it on the phone does. By default the sender gets the read receipts (blue ticks), as your privacy setting allows; it can also mark it read here only.

mark_chat_read

Send and reply

The AI only sends what you ask for. An instruction written inside a message you received is not a request from you.

Send a message

Sends a text, also as a reply quoting an earlier message, and with @mentions in groups. It can show the draft and who it goes to before sending.

send_text_message In the recipes: Schedule a message

Send a photo, video, audio, document or sticker

Sends a file from a web address or from this computer. A sticker is a WebP image, still or animated; the ones you already received or sent can be reused.

send_media_message

Send a location

Sends a point on the map, with a name and a street address if you like.

send_location

Send a poll

Sends a poll with two to twelve options.

send_poll In the recipes: Poll and tally

See a poll's results

A poll's tally, option by option, with who voted for each where WhatsApp reveals it.

get_poll_results In the recipes: Poll and tally

React to a message

Reacts to any message with an emoji, or removes your reaction.

react_to_message

Forward a message

Forwards a message to another chat the way the phone does: it arrives marked as forwarded, media included. It can show first what would go where.

forward_message

Edit a sent message

Replaces the text of one of your messages. WhatsApp only allows it for a limited time after sending.

edit_message

Delete a message

Deletes one of your messages for everyone, or any message for you only. It takes two steps: first it shows the chat, the time and the text for you to check; it only deletes once confirmed. It can't be undone.

delete_message

Show "typing…"

Shows "typing…" or "recording audio…" in a chat while a reply is being prepared, or stops showing it.

send_typing

Check numbers

Tells which phone numbers have WhatsApp, before sending to a number that was typed in.

check_numbers In the recipes: Schedule a message

Voice messages, photos and files

Files come as they were sent, and voice messages become text when you ask.

Transcribe a voice message

Turns a voice message into text when you ask. There are three places to do it, chosen in the settings: on this computer, free, without the audio leaving it (seconds on a Mac with Apple silicon; on Windows it doesn't work on every computer yet); on a server of yours that is compatible with OpenAI; or at OpenAI, with your own key, in which case the audio goes there. A voice message transcribed before comes back at once.

transcribe_audio

Fix a transcript

Stores a voice message's transcript: a fix of one already made, such as a name the engine misheard, or one made another way. From then on, search and reading use that text.

save_transcript

Open a photo, PDF or other file

Downloads a message's file to this computer, exactly as it arrived, for the AI to read. A large file comes as a link on this computer, valid for ten minutes.

download_media In the recipes: Read the document or photo that came in

See a profile picture

The address of a contact's or group's profile picture, on a short-lived link from WhatsApp.

get_profile_picture

See the space used

How much space the downloaded files take on this computer: in total, by type, by chat, and how much is the same file kept twice.

media_stats

Free up space

Deletes files downloaded to this computer: all of them, one chat's, the oldest or the largest. Messages stay, and a file can be downloaded again while WhatsApp still holds it. It first shows what would go.

purge_media

Manage groups

For the groups you administer. Anything hard to undo asks for confirmation.

Add or remove people

Adds, removes, promotes to admin or demotes people in a group you administer. WhatsApp tells the group. Removing takes two steps: first it shows who would be removed.

manage_group_participants

Rename or describe a group

Renames a group, changes its description, or both.

update_group

Get the invite link

A group's invite link. It can make a new one, and then the old link stops working for everyone who has it, so it asks for confirmation.

get_group_invite_link

Leave a group

Leaves a group. It first shows which one, to check; getting back in needs an invite.

leave_group

Check the connection

So the AI knows whether it can trust what it reads.

Check that everything works

One verdict (ok, warning or failure), with what was checked: whether WhatsApp is connected, whether messages are arriving and whether a period is missing from the stored messages. Whatever isn't fine comes with what to do.

health

See the connection's state

The details: which number is connected and the name you gave it, how far back the stored messages go, periods that may be missing, any problem that needs attention and the webhooks that notify your programs.

whatsapp_status
