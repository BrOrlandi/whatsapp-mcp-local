Enquete e apuração

Mandar a enquete e voltar depois para ler o resultado são duas chamadas separadas, ligadas pelo id que a primeira devolve.

Quando
Envio agora, apuração depois
Ferramentas que usa
Enviar uma enquete Ver o resultado de uma enquete

O texto para colar

Mande no grupo do time uma enquete:
"Churrasco sexta?" com as opções Sim, Não e Talvez.

Guarde o message_id. Amanhã às 17h, leia o resultado
com get_poll_results e me diga a contagem.

Atenção: Sem guardar o message_id não há como apurar. Peça ao assistente para anotá-lo junto com a tarefa de leitura.

Como usar

  1. Baixe o WhatsApp MCP e conecte o seu WhatsApp com o QR code.

  2. Conecte a sua ferramenta de IA: o Claude Desktop e o Claude Code com um clique; as outras com um texto pronto.

  3. Cole o texto no chat da ferramenta, trocando o que estiver entre colchetes. Quando a receita tem horário, quem espera a hora é a ferramenta de IA: use uma que saiba agendar tarefas.

Outras receitas

  • Agendar uma mensagem
  • Vigiar palavras-chave
  • Resumo do que ficou sem resposta
  • Resumo do dia de um grupo
  • Ler o documento ou a foto que chegou
  • Arquivo do que foi combinado
